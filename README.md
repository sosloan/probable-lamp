## data-is-code

A Clojure application demonstrating **homoiconicity** — *data is code is data*.

See [`data-is-code/README.md`](data-is-code/README.md) for full documentation.

### Quick start

```bash
cd data-is-code
clojure -M:run   # Clojure CLI
# or
lein run         # Leiningen
```
